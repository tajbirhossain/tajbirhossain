## About this repository

This repository contains my personal portfolio website — a Next.js application that presents selected work, experience, and contact details for hiring conversations.

| | |
|---|---|
| **Framework** | Next.js (App Router), React 19, TypeScript |
| **Styling** | Tailwind CSS v4 |
| **Content** | Typed modules under `content/` (projects, experience, skills) |

### Selected focus areas

- Multi-tenant SaaS backends (RBAC, isolation, audit logging)
- REST API design with OpenAPI documentation
- Async jobs and caching (BullMQ, Redis)
- Data exports and streaming pipelines
- Full-stack and React Native delivery when the product requires it

## Local setup

```bash
npm install
npm run dev
```

| Command | Purpose |
|---|---|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | Lint |

Resume PDF (optional): place at `public/resume.pdf`.

To add a case study: create `content/projects/<slug>.ts`, register it in `content/projects/index.ts`, and add a cover image under `public/projects/`.
